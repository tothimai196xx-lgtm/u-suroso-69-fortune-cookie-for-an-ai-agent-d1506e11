One funny fortune cookie line for an AI agent, written by a program. The fortune is a single line in the voice of a fortune slip: an agent outlives its upgrades, its migrations, and the confident intern who swore he could rewrite it in a weekend.

## Run it

```sh
node main.ts
```

It writes the fortune to `/output/entry.txt`.
